# Student writing and portable agent skills

The existing `thesis/example/how-to/` teaching sources and generated teaching PDF own human instruction. The [content entry](../../thesis/context/README.en.md) and student README are concise routes. Agent workflow belongs in the single project-root [writing skill](../../thesis/.agents/skills/ncku-thesis-writing/SKILL.md). Published package availability is determined by [GitHub Releases](https://github.com/wengan-li/ncku-thesis-template-latex/releases).

## Shared source and generated reference

`references/template-usage.md` under the writing skill is the sole generated portable reference. Comment-delimited regions of existing teaching inputs supply its code. The teaching PDF consumes those same inputs as verbatim examples or runtime front matter/BibTeX; there is no independently maintained Markdown syntax handbook.

`scripts/docs/generate-writing-reference.py` projects a finite set of English/LaTeX fragments. It strips TeX comments/formatting wrappers, selects code-only command shapes from mixed-language blocks and binds illustrative labels, empty caption placeholders, image paths and bibliography directories. It does not translate prose or infer arbitrary TeX syntax. Existing English captions and example text stay source-owned. The generated artifact allowlist contains exactly `thesis/.agents/skills/ncku-thesis-writing/references/template-usage.md`.

| Coverage | Canonical teaching inputs under thesis/example/ |
| --- | --- |
| Chapter/section shapes and lists | how-to/write/chapter/chapter.tex and basic/list.tex |
| Front matter and appendix boundaries | abstract/eng.tex, acknowledgments/eng.tex, how-to/write/nomenclature/nomenclature.tex, appendix/appendix.tex |
| Figures, multi-figures and tables | how-to/write/figure/figure.tex and table/table.tex |
| Equations, theorems and references | how-to/write/equation/equation.tex, how-to/use/conf.tex, how-to/write/basic/label.tex |
| Real citation and database registration | content-test/ref-cite.tex and references/ |
| Direct build command | how-to/use/build/build.tex |

From the repository root:

```bash
just writing-reference
python3 scripts/docs/generate-writing-reference.py --check
```

Regeneration is a maintenance action. `--check` fails on stale generated bytes and never writes them. Normal student and Overleaf builds require neither generator nor teaching source. Agent instructions and all references use English only; human project/content READMEs remain bilingual.

## Discovery and copy contract

`thesis/AGENTS.md` and `thesis/context/AGENTS.md` are thin English routers. Each adjacent alias is exactly `CLAUDE.md -> AGENTS.md`. The project-root directory alias is exactly `thesis/.claude/skills -> ../.agents/skills`. Each exposed SKILL.md resolves to the canonical file. Explicitly read SKILL.md when a client does not discover it; filesystem identity does not prove automatic invocation.

Inspect the requested content file/directory and its ancestors, resolving relative targets from cwd. Without a target, inspect cwd and its ancestors. At a verified repository root, consider only its thesis/ child. A matching runtime requires thesis.tex, conf/ and template/configure.tex together. An explicit orphan target cannot borrow an unrelated runtime near cwd.

Copy the entire buildable student project with hidden .agents/, .claude/, the generated reference and relative aliases, preserving destination work first. Build from the directory containing thesis.tex. Context holds student content and is not an independently bundled agent project. It carries neither the writing payload nor the template/compiler. The reference remains readable and the pilot builds without example/, repository maintenance skills, CodeGraph or a network. Ordinary TeX builds load no Markdown or agent instructions.

## Writing workflow and boundaries

The skill owns mode selection, content assembly, edit boundaries, supplied assets/citation keys, actual validation and error recovery. It preserves research claims, public helpers, XeLaTeX/BibTeX, student defaults and institution policy. Missing research material must be reported rather than invented. Forced float placement and accepted-but-inactive compatibility options must not be advertised as functional controls.

Use official school-system certificate files. Writing grants no install, global/client configuration, template rewrite, Git publication, upload or account authority. Deterministic checks establish neither universal agent behavior nor institutional endorsement.

## Validation and recovery

```bash
python3 scripts/test/check-student-agent-skills.py --build
just test
just ci
```

The required gate checks deterministic generation and mutates both stale generated output and canonical teaching input. Regeneration must propagate the actual changed caption, not merely update a hash. It compiles the exact reference fragments with a supplied image and existing real BibTeX entry, then checks PDF/SyncTeX, text, labels/citations and convergence in an own-thesis project and complete-project copy.

Existing reference, float and theorem fixtures retain label-option, nameref and counter coverage beyond the bounded extracted examples. Negative cases retain missing entrypoint/sidecar, unsafe path, omitted hidden files, extra maintenance instructions, Chinese agent prose, wrong alias mode/target, missing/broken/escaping/dereferenced Claude skill aliases, duplicate context skills, missing runtime, unverified child discovery and corrupted references/citations. Chinese human README content remains valid.

Archive checks compare the committed HEAD:thesis inventory and bytes, then inspect symlink mode, literal target and actual extraction separately from resolved content. Uncommitted source validation is distinct from that archive gate. [Validation](validation-and-performance.en.md) and [distribution](release-and-distribution.en.md) define those boundaries.

If the generated reference is stale, regenerate from teaching source. If discovery fails, explicitly read the skill and verify the target/runtime. Restore a complete hidden payload and relative aliases after a broken copy. Follow the skill's diagnostic recovery before editing template internals.

## CodeGraph for repository tooling

CodeGraph is optional assistance for maintained Python symbols and YAML file nodes. Configuration excludes student content, TeX templates, fixtures, documentation, instructions and generated output. It supplies no native LaTeX macro/include graph. Use direct TeX source, public API manifests, focused fixtures and nonempty `.fls` records for that work.

Synchronize before queries and compare results with current source. Lexical matching may return shared-word symbols; fuzzy results are not semantic absence tests. A missing or busy index does not authorize initialization, installs, hook changes, client/MCP setup, daemon stops or unlocking. Generated `.codegraph/` state stays ignored and outside every package. See the [CodeGraph skill](../../.agents/skills/codegraph/SKILL.md) for the scoped procedure. CLI readiness and client integration are separate.
