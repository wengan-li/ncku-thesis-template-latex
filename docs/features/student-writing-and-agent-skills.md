# 學生寫作與可攜式代理技能

狀態：本機實作及驗收已完成，尚未發行。本頁不代表現有下載套件已包含此功能。

## 目標與邊界

本專案將寫作知識放入 `thesis/context/.agents/skills/ncku-thesis-writing/`，技能及學生代理路由僅用英文。繁中與英文的人用指南放在 `context/usage/`，由技能按任務連至英文指南。學生與代理共用同一份用法說明；複製完整 `context/` 時須包含隱藏目錄與符號連結。內容目錄本身不含論文範本執行環境，仍須搭配相符的完整論文專案。

學生專案及內容目錄各有一份 `AGENTS.md` 路由；相鄰 `CLAUDE.md` 必須是指向 `AGENTS.md` 的相對符號連結。兩者不授予儲存庫發行權限。一般論文建置不讀取技能，也不需要 CodeGraph、網路或教學範例。

## 驗收與狀態

驗收涵蓋自己的章節、圖片、圖說、標籤、交叉引用與既有真實 BibTeX 文獻，並直接編譯文件刊載的片段。另驗證解壓縮後的學生套件、完整內容目錄複製、Overleaf 套件本機冷建置與缺檔等反向案例。英文記錄保存來源對照與實際證據。兩項完整測試閘門、解壓縮後的預設建置、自己的論文片段及整份內容目錄複製均已通過。預設輸出保留 261 頁 A4 與 SyncTeX。

本次保留 XeLaTeX、BibTeX、既有設定及可見版面。代理不得虛構研究結果、引用或機構核可，也不得把產生的證明書當成官方文件。Git 發行及 Overleaf 上傳不在本次範圍。
