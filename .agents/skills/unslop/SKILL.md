# Unslop

For prose revisions, read the [pattern checklist](references/upstream-SKILL.md)
and apply the patterns relevant to the text. The archived source frontmatter is
provenance, not invocation policy.

Preserve facts, commands, numbers, citations, uncertainty and the requested tone.
Do not invent opinions, experiences or supporting evidence. Keep complete,
readable sentences and the repository's third-person public voice. Shorten text
without dropping decisions, limitations or necessary instructions.

Keep release notes to a few short user-facing changes. Put test reports and
implementation logs in technical records, not release bullets. Return the final
text without an editing audit unless requested.

The checklist retains upstream rule IDs. See [provenance](references/provenance.md)
and the [MIT license](references/LICENSE).
