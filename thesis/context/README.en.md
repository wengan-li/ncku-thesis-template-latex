# Thesis content and writing entry

## Learn to write

Write chapters under `context/` and select their inputs in `context/context.tex`. Before writing your own thesis, enter your information and turn off `\ExampleMode` following the [student project guide](../README.en.md).

For chapters, figures, tables, equations, theorems, bibliography and front matter, follow the [teaching PDF download instructions](../README.en.md#start-writing). Teaching sources also remain under `example/how-to/`. The downloaded PDF is still usable after that directory has been removed.

## Use an agent or copy the project

For AI assistance, ask the agent to read [SKILL.md](../.agents/skills/ncku-thesis-writing/SKILL.md) first, then consult the [English helper reference](../.agents/skills/ncku-thesis-writing/references/template-usage.md) as needed. If the client does not find the skill automatically, provide the SKILL.md path explicitly.

Preserve destination work before copying the entire student project, including hidden `.agents/`, `.claude/` and relative links. Do not copy only `context/`. Build from the directory containing `thesis.tex`.

If the agent reports `A matching complete thesis template containing thesis.tex, conf/ and template/configure.tex is required.`, obtain the complete student package first. Preserve your own content and data, then build following the [student project guide](../README.en.md). Do not substitute an unrelated project.
